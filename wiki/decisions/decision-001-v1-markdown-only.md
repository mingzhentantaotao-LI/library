# Decision 001：V1 保持 Markdown-only

## 状态

已采纳

## 日期

2026-04-22

## 决策

个人知识库 V1 只采用 Markdown 和目录结构管理知识，不引入前端、数据库或复杂 RAG 基础设施。

## 理由

- 当前目标是先建立可持续维护的知识整理习惯，而不是建设复杂系统。
- Markdown 与目录结构已经足以表达来源、摘要、索引、回链和决策。
- 轻量结构更容易长期维护，也更容易审查来源是否可追溯。

## 影响

- 所有稳定知识沉淀优先写入 `wiki/`。
- 原始资料继续保留在 `raw/`，不通过数据库再建一层映射。
- 如未来扩展，也应先保证现有 `raw/ + wiki/` 结构依然成立。
